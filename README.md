# Гусейн Бабаев

Студент направления информационной безопасности.

## Целевое направление

- сетевой мониторинг;
- NOC L1;
- SOC L1;
- анализ журналов и первичный разбор инцидентов.

## Практика

- собственная учебная лаборатория с Linux-подобными журналами;
- Python для обработки синтетических событий;
- документирование временной шкалы, наблюдений и ограничений;
- Git и GitHub для публикации технических материалов.

## Избранный проект

[Моя SOC-лаборатория](https://github.com/deyzaneck/soc-home-lab)

Все примеры в проекте синтетические: реальные журналы, учётные данные и данные организаций не публикуются.
